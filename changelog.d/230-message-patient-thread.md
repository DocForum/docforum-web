Phase W3: "Message patient" in the abnormal results inbox now opens the doctor's existing care thread with that patient instead of logging the patient name to the console ([issue #230](https://github.com/DocForum/docforum-web/issues/230)). The lookup walks every page of the thread list, one request for the whole inbox, so a patient whose thread is beyond the first page still gets the action; rows whose patient has no thread show no message button. No new API shape is assumed — `DoctorMessageThread` already carries `patientProfileId`.
