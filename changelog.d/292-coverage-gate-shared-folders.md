Phase W7: put the shared components and hooks under the coverage gate ([issue #292](https://github.com/DocForum/docforum-web/issues/292)).
`npm run test:coverage` now measures `src/components/**` and `src/hooks/**` alongside `src/features/**` and `src/services/**`, so a primitive used by every screen can no longer lose all its tests without CI noticing. Each new folder also gets its own threshold floor in `vite.config.ts` (`src/components/**` 87/82/89/88, `src/hooks/**` 95/89/95/97) so one folder cannot slide to zero while the aggregate still clears it. The existing aggregate floors (78/70/77/79) are unchanged — the two folders are better covered than the average, so adding them raised the measured total to 82.7/74.6/81.5/84.8 instead of requiring a lower floor. Floors and what they gate are recorded in `ARCHITECTURE_ESSENTIALS.md`.
