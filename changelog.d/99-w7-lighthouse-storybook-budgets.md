This PR also repairs CI itself: `package-lock.json` had lost the rollup/esbuild platform binaries to npm's optional-dependency pruning, so `npm run test` died at Vitest startup on Linux runners (the lockfile was rebuilt from `main`'s healthy copy); `DataTable.stories.tsx`'s stubbed CSF default export was replaced with real `@storybook/react-vite` types so Storybook can index it; Zod now runs in `jitless` mode (`src/zod-csp.ts`, first import of `main.tsx`) so the strict production CSP from #101 stays in force without a TrustedScript console error on every page; and `frame-ancestors` was dropped from the `<meta>` CSP (Chrome ignores it there and logs an error — it is only enforceable via an HTTP header, which GitHub Pages cannot set). Lighthouse budgets were calibrated against measured baselines before the first green run: script size 330 000 (observed 299 KB) and LCP ≤6000 ms (observed worst run 4.96 s), both still failing on regression, while the three preset gates that cannot pass by construction — `unused-javascript`/`unused-css-rules` items = 0 and `network-dependency-tree-insight` (fails any critical chain of length ≥2, i.e. any page with a stylesheet or a lazy chunk) — are set to `warn` so they stay visible in every run's Lighthouse output instead of permanently blocking CI.
