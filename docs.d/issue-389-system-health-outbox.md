For the Phase W6 system health page, the outbox tile reads `GET /admin/outbox/dead-letters?limit=50`. The response contains only dead-letter metadata (`id`, `type`, `attempts`, `lastError`, `createdAt`, and `deadLetteredAt`); payloads are not exposed. The UI shows the number returned, uses `50+` when the page is full, and displays up to five recent entries. It does not claim pending counts or queue age.
